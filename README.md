# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/SoubiaIfra/Rock-Paper-Scissors-Game.git
```

## 2️⃣ Navigate to the Project

```bash
cd Rock-Paper-Scissors-Game
```

## 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

## 4️⃣ Activate the Environment

### Windows

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
source venv/bin/activate
```

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 6️⃣ Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

# 🎯 Gameplay

1. Launch the game.
2. Click **Play**.
3. Choose **Rock**, **Paper**, or **Scissors**.
4. The computer randomly selects its move.
5. The winner is instantly displayed.
6. Continue playing as many rounds as you like.
